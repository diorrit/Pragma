Натисни гарячу клавішу — скриншот піде в нейромережу, вона відповість на питання з екрана і надішле відповідь у Telegram. Опційно — відповідь з'являється прямо поверх екрана в прихованому від OBS оверлеї.

## Можливості

- **Скриншот за гарячою клавішею** — натиснув `F8`, отримав відповідь. Працює з **кількома моніторами** (захоплює той, де знаходиться курсор).
- **Два режими виводу**: тільки Telegram або Telegram + оверлей поверх екрана
- **Чотири нейромережі**: Mistral (за замовчуванням), Gemini, OpenAI (GPT-4o), Anthropic (Claude 3.5 Sonnet)
- **Локальний OCR (Tesseract)**: автоматично намагається витягти текст із екрану локально перед зверненням до AI для економії токенів і часу.
- **Логування**: зберігає питання та відповіді у файл `history.log` за бажанням.
- **Кастомізація промптів**: усі системні запити до ШІ зберігаються у `prompts.json` і легко змінюються.
- **Автоматичний fallback**: якщо одна модель вичерпала ліміт — автоматично переключається на наступну
- **Керування через Telegram**: зробити скрін, змінити модель, перевірити статус — прямо з телефону
- **Оверлей невидимий для OBS** та будь-якого screen capture (Windows 10 20H1+)
- **Регульована прозорість оверлея** — повзунок від 20% до 100%, повністю прозорим зробити не можна
- **Drag & drop**: переміщення оверлея мишею за заголовок
- **Клік наскрізь**: режим, коли оверлей не перехоплює кліки миші
- **Автоховання**: оверлей зникає сам після показу відповіді

## Встановлення (Windows)

### 1. Встановіть Python та Tesseract OCR

1. Завантаж з [python.org](https://www.python.org/downloads/) (версія 3.10+). При встановленні постав галочку **"Add Python to PATH"**.
2. Встановіть [Tesseract-OCR](https://github.com/UB-Mannheim/tesseract/wiki). При встановленні оберіть українську та російську мови.

### 2. Встановіть залежності

Відкрий термінал у папці з проєктом і виконай:

```
pip install -r requirements.txt
```

### 3. Налаштуй `.env`

Скопіюй файл `.env.example` → `.env` і заповни своїми ключами:

```
cp .env.example .env
```

Відкрий `.env` у будь-якому текстовому редакторі.

### 4. Запуск

**Через термінал:**
```
python main.py
```

**Без консолі (подвійний клік):**
```
start.bat
```

**Зупинити:**
```
stop.bat
```
або натисни `Ctrl + Alt + Shift + Q`.

## Де брати ключі

### Telegram Bot Token (`BOT_TOKEN`)

1. Відкрий Telegram → [@BotFather](https://t.me/BotFather)
2. Надішли `/newbot`, придумай ім'я і юзернейм (юзернейм має закінчуватись на `bot`)
3. Скопіюй токен вигляду `1234567890:AAH...` у `BOT_TOKEN`

### Telegram Chat ID (`CHAT_ID`)

1. Напиши що-небудь своєму боту (інакше бот не зможе знайти твій chat_id)
2. Відкрий [@userinfobot](https://t.me/userinfobot) → `/start`
3. Скопіюй своє `Id` у `CHAT_ID`

### Mistral API Key (`MISTRAL_API_KEY`)

1. Зареєструйся на [console.mistral.ai](https://console.mistral.ai)
2. Розділ **API Keys** → **Create new key**
3. Скопіюй ключ у `MISTRAL_API_KEY`

### OpenRouter API Key (`OPENROUTER_API_KEY`) — для Gemini, OpenAI, Anthropic

1. Зареєструйся на [openrouter.ai](https://openrouter.ai/keys)
2. Створи ключ, скопіюй у `OPENROUTER_API_KEY`

## Файл `.env` — всі параметри

```env
BOT_TOKEN=...         # токен Telegram-бота
CHAT_ID=...                  # твій Telegram ID
MISTRAL_API_KEY=...                 # ключ Mistral
OPENROUTER_API_KEY=sk-or-v1-...    # ключ OpenRouter
HOTKEY=f8                           # гаряча клавіша для скриншоту
QUIT_HOTKEY=ctrl+alt+shift+q        # гаряча клавіша для виходу
SOLVER_MODEL=mistral-large-latest   # модель для вирішення задач
ENABLE_LOGGING=true                 # логувати запити у history.log
```
