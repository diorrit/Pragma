Натисни гарячу клавішу — скриншот піде в нейромережу, вона відповість на питання з екрана і надішле відповідь у Telegram. Опційно — відповідь з'являється прямо поверх екрана в прихованому від OBS оверлеї.

---

## Можливості

- **Скриншот за гарячою клавішею** — натиснув `F8`, отримав відповідь
- **Два режими виводу**: тільки Telegram або Telegram + оверлей поверх екрана
- **Дві нейромережі**: Gemini (швидко, коротко) і Mistral (докладно, крок за кроком)
- **Автоматичний fallback**: якщо Mistral вичерпав ліміт — автоматично переключається на Gemini
- **Керування через Telegram**: зробити скрін, змінити модель, перевірити статус — прямо з телефону
- **Оверлей невидимий для OBS** та будь-якого screen capture (Windows 10 20H1+)
- **Регульована прозорість оверлея** — повзунок від 20% до 100%, повністю прозорим зробити не можна
- **Drag & drop**: переміщення оверлея мишею за заголовок
- **Клік наскрізь**: режим, коли оверлей не перехоплює кліки миші
- **Автоховання**: оверлей зникає сам після показу відповіді

## Встановлення (Windows)

### 1. Встановіть Python

Завантаж з [python.org](https://www.python.org/downloads/) (версія 3.10+).
При встановленні постав галочку **"Add Python to PATH"**.

### 2. Встановіть залежності

Відкрий термінал у папці з проєктом і виконай:

```
pip install -r requirements.txt
```

### 3. Налаштуй `.env`

Скопіюй файл `.env.example` → `.env` і заповни своїми ключами:

```
cp .env.example .env
```

Відкрий `.env` у будь-якому текстовому редакторі (Блокнот, Notepad++, VS Code).

### 4. Запуск

**Через термінал:**
```
python screen_tg.py
```

**Без консолі (подвійний клік):**
```
start.bat
```

**Зупинити:**
```
stop.bat
```
або натисни `Ctrl + Alt + Shift + Q`.

## Де брати ключі

### Telegram Bot Token (`BOT_TOKEN`)

1. Відкрий Telegram → [@BotFather](https://t.me/BotFather)
2. Надішли `/newbot`, придумай ім'я і юзернейм (юзернейм має закінчуватись на `bot`)
3. Скопіюй токен вигляду `1234567890:AAH...` у `BOT_TOKEN`

### Telegram Chat ID (`CHAT_ID`)

1. Напиши що-небудь своєму боту (інакше бот не зможе знайти твій chat_id)
2. Відкрий [@userinfobot](https://t.me/userinfobot) → `/start`
3. Скопіюй своє `Id` у `CHAT_ID`

### Mistral API Key (`MISTRAL_API_KEY`)

1. Зареєструйся на [console.mistral.ai](https://console.mistral.ai)
2. Розділ **API Keys** → **Create new key**
3. Скопіюй ключ у `MISTRAL_API_KEY`

> Є безкоштовний тир без прив'язки карти.

### OpenRouter API Key (`OPENROUTER_API_KEY`) — для Gemini

1. Зареєструйся на [openrouter.ai](https://openrouter.ai/keys)
2. Створи ключ, скопіюй у `OPENROUTER_API_KEY`

> Потрібен лише якщо плануєш використовувати режим Gemini.

## Файл `.env` — всі параметри

```env
BOT_TOKEN=1234567890:AAH...         # токен Telegram-бота
CHAT_ID=123456789                   # твій Telegram ID
MISTRAL_API_KEY=...                 # ключ Mistral
OPENROUTER_API_KEY=sk-or-v1-...    # ключ OpenRouter (для Gemini)
HOTKEY=f8                           # гаряча клавіша для скриншоту
QUIT_HOTKEY=ctrl+alt+shift+q        # гаряча клавіша для виходу
SOLVER_MODEL=mistral-large-latest   # модель для вирішення задач
```

**Приклади значень для `HOTKEY`:**
```
HOTKEY=f8
HOTKEY=f12
HOTKEY=ctrl+shift+s
HOTKEY=alt+f9
```

## Як користуватись

### При запуску

З'являється вікно вибору режиму виводу:

- **📱 Telegram** — відповідь надсилається тільки в Telegram
- **🪟 Overlay** — відповідь з'являється поверх екрана І надсилається в Telegram

Після вибору бот активується і надсилає повідомлення у Telegram з підтвердженням.

### Гаряча клавіша

Натисни `F8` (або іншу, яку вказав у `.env`) — програма:
1. Робить скриншот усього екрана
2. Витягує текст питання/завдання через Pixtral (vision-модель)
3. Вирішує задачу через Mistral Large або Gemini
4. Надсилає коротку відповідь у Telegram (і показує в оверлеї, якщо обраний)

### Telegram-панель

Після запуску в Telegram з'являється клавіатура з кнопками:

| Кнопка | Дія |
|---|---|
| 📸 Зробити скрін | Те саме, що натиснути гарячу клавішу |
| 🔄 Змінити модель | Перемикає між Mistral ⚡ і Gemini ✨ |
| ℹ️ Статус | Показує активну модель, режим виводу та стан токенів |
| ❌ Зупинити бот | Завершує програму |

## Оверлей — докладно

Оверлей — темно-синє вікно, яке з'являється поверх усіх вікон і **невидиме для OBS** та інших програм захоплення екрана.

### Елементи інтерфейсу

```
┌─────────────────────────────────────────────┐
│ ✨ SCREEN SOLVER OVERLAY          🔆   ✕	  │  ← заголовок
├─────────────────────────────────────────────┤
│                                             │
│  ✨ [GEMINI]								  │  ← відповідь
│  Правильна відповідь: В — 42				  │
│                                             │
└─────────────────────────────────────────────┘
```

- **🔆** — відкриває повзунок прозорості
- **✕** — сховати оверлей (не закриває програму)
- **Перетягування**: утримуй ЛКМ на заголовку або тілі оверлея

### Регулювання прозорості

Натисни кнопку **🔆** у заголовку або вибери **"🔆 Прозорість..."** з контекстного меню (ПКМ).

У вікні повзунка:
- Діапазон: від **20%** до **100%**
- Повністю прозорим зробити **неможливо** — мінімум 20%
- Зміна застосовується одразу, без перезапуску
- Натисни **"Застосувати"** або просто закрий вікно

### Контекстне меню (ПКМ)

Клікни правою кнопкою миші на оверлеї:

| Пункт | Дія |
|---|---|
| Очистити | Прибирає текст і ховає оверлей |
| Сховати на 5 сек | Тимчасово ховає, потім повертає |
| Клік наскрізь | Оверлей перестає перехоплювати кліки миші |
| 🔆 Прозорість... | Відкриває повзунок прозорості |
| Закрити оверлей | Завершує програму |

## Моделі

### ⚡ Mistral (за замовчуванням)

- **Витягує питання**: Pixtral-12b (vision)
- **Вирішує**: Mistral Large Latest
- **Відповідь**: коротка, 1–2 речення
- **Ключ**: `MISTRAL_API_KEY`

### ✨ Gemini

- **Витягує питання**: Gemini 2.5 Flash (через OpenRouter)
- **Вирішує**: Gemini 2.5 Flash — докладно, крок за кроком
- **Стискає**: Mistral Large до одного рядка перед відправкою
- **Ключ**: `OPENROUTER_API_KEY`

### Автоматичний fallback

Якщо Mistral вичерпав безкоштовний ліміт токенів — програма автоматично переключиться на Gemini і повідомить про це в Telegram. Вручну перемикати не потрібно.

## Вирішення проблем

### `No module named 'X'`

```
pip install -r requirements.txt
```

Якщо помилка залишається для конкретного пакету:
```
pip install назва_пакету
```

### Бот не надсилає повідомлення при запуску

- Перевір `BOT_TOKEN` — він має бути без пробілів
- Переконайся, що написав хоч одне повідомлення боту в Telegram
- Перевір `CHAT_ID` — має бути числом, наприклад `123456789`

### Гаряча клавіша не спрацьовує

- На Windows потрібні права адміністратора для деяких клавіш (`F1`–`F12` зазвичай OK)
- Переконайся, що інша програма не перехоплює цю клавішу
- Спробуй іншу комбінацію, наприклад `ctrl+shift+s`

### Помилка авторизації Mistral (401)

- Ключ `MISTRAL_API_KEY` недійсний або прострочений
- Згенеруй новий на [console.mistral.ai](https://console.mistral.ai)

### Оверлей видно в OBS

- Функція приховування від OBS підтримується тільки на **Windows 10 build 2004 (20H1)** і новіших
- Перевір версію Windows: `Win + R` → `winver`
